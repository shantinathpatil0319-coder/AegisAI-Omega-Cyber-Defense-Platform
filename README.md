# 🛡️ AegisAI - AI Cyber Defense Platform

AegisAI is an AI-based cybersecurity platform designed to detect and monitor potential cyber threats. It analyzes login activities, IP addresses, security events, and system logs to identify suspicious behavior.

## 🚀 Features

- 🔐 Login and security monitoring
- 🚨 Suspicious login detection
- 🤖 AI/ML-based threat detection
- 🌐 IP address monitoring
- 📊 Cyber threat dashboard
- ⚡ Real-time security alerts
- 📋 Security activity logs
- 👨‍💻 Admin dashboard
- 📈 Threat statistics
- 🚫 IP blacklist and whitelist
- 📧 Email notifications
- 🧠 AI security assistant

## 🛠️ Technologies Used

- Python
- Flask
- Machine Learning
- MySQL / SQLite
- HTML
- CSS
- JavaScript

## 🎯 Objective

The main objective of AegisAI is to provide a simple and intelligent cybersecurity platform that helps detect suspicious activities, analyze potential threats, and assist administrators in monitoring and protecting applications.

## 🔄 How It Works

1. User accesses the AegisAI platform.
2. Login and security activities are monitored.
3. Suspicious behavior is analyzed.
4. The threat detection system classifies potential threats.
5. Security events are stored in the database.
6. Administrators can view the results through the dashboard.
7. Alerts are generated for important security events.
8. Suspicious IP addresses can be blocked or managed.

## 📊 Security Dashboard

The dashboard provides information about:

- Detected threats
- Login attempts
- Suspicious IP addresses
- Security events
- Attack statistics
- Security logs
